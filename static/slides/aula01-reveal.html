Root Cause Analysis

O Código que Derrubou a Produção

// PerguntaController.php  —  versão atual em produção
public function index()
{
    // ⚠ Carrega TODOS os registros da tabela na memória
    $perguntas = Pergunta::all();

    return view('perguntas.index', compact('perguntas'));
}

Com 5.000 perguntas → PHP aloca ~40MB por requisição. Com 10 usuários simultâneos → 400MB. O servidor dorme.

Ticket #002 · Fix

Paginação: entregue 10, não 5.000

// PerguntaController.php  —  versão corrigida
public function index(Request $request)
{
    $perguntas = Pergunta::query()
        ->when($request->search, fn($q, $v) =>
            $q->where('texto', 'like', "%{$v}%")
        )
        ->latest()
        ->paginate(10);   // ← banco devolve só 10 linhas

    return view('perguntas.index', compact('perguntas'));
}

Status: 200 OK · Query time: < 5ms · Memória: -97% 🎉
