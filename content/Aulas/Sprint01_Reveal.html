🎫 Os Tickets Abertos

#001 — Spam no Banco
Perguntas vazias e com 1 letra estão chegando via API. Precisamos bloquear na entrada.
#002 — Timeout na Listagem
Pergunta::all() carrega 5.000 registros de uma vez. O servidor trava em <2s.

💀 O Código Culpado


// PerguntaController.php — Hoje
public function index()
{
    $perguntas = Pergunta::all(); // ← BOMBA RELÓGIO
    return view('perguntas.index', compact('perguntas'));
}

O que acontece quando tem 5.000 perguntas?

💡 Ticket #002: Paginação

Solução: paginate(10) 

// PerguntaController.php — Depois
public function index(Request $request)
{
    $perguntas = Pergunta::query()
        ->latest()
        ->paginate(10);

    return view('perguntas.index', compact('perguntas'));
}

O banco devolve apenas 10 linhas. O servidor respira. ✅

💡 Ticket #001: Validação

Solução: php artisan make:request StorePerguntaRequest 

// StorePerguntaRequest.php
public function rules(): array
{
    return [
        'texto' => ['required', 'min:10', 'max:255'],
    ];
}

Status 422 para lixo. Status 201 para dados válidos. ✅
